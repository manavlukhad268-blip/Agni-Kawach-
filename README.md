# Agni Kawach - Smart Hazard & Fire Detection

## 🚀 Overview
**Agni Kawach** is a smart vision application designed to solve a major limitation in traditional fire safety systems: the inability to differentiate between controlled, safe domestic activities (such as cooking on a gas stove) and hazardous, unattended fires. 

## 🛠️ Tech Stack & Architecture
- **Frontend / UI:** Bolt.new
- **AI & Processing Logic:** YOLOv8 / Computer Vision
- **Image Handling:** OpenCV
- **Deployment:** Scalable cloud-ready architecture (AWS)

## 📌 Features
- **Smart Classification:** Distinguishes between safe controlled flames and unsafe hazards.
- **Automated Alerts:** Triggers siren notifications upon detecting unattended fire threats.
- **Clean Interface:** Streamlined file upload and hazard analysis workflow.
